📋 Task Checklist

🚧 **Projeto em desenvolvimento**

Um aplicativo prático e direto para organização de tarefas do dia a dia, focado em clareza e controle.

📌 Sobre o Projeto

O objetivo do projeto é oferecer uma ferramenta simples para gerenciamento de pendências. 

Para garantir a organização e evitar confusões com tarefas vazias ou acidentais, o sistema exige obrigatoriamente a inclusão de um **nome/título para a tarefa** antes de registrá-la. Isso assegura que cada item do checklist seja claro e realmente útil para o usuário.

🛠️ Tecnologias

*Front-end: HTML5, CSS3 e JS*
